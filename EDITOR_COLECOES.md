# Editor de Coleções

Novo editor visual disponível no Designer para:

- ComboBox.Items
- ListBox.Items
- CheckedListBox.Items
- DataGridView.Columns
- TabControl.TabPages
- TreeView.Nodes

A coleção é editada em uma janela própria, salva dentro do `.flowapp`,
restaurada ao reabrir o projeto e também recriada no executável compilado.

Acesso:
- Ferramentas -> Editar coleção...
- barra Designer -> Coleção

O recurso é compartilhado pelas edições Studio e Education.

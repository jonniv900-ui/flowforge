# Organização do menu Projeto

Os comandos de criação e gerenciamento de itens foram agrupados em:

`Projeto -> Itens do projeto`

O submenu contém:
- Adicionar Form
- Adicionar Classe
- Adicionar Módulo
- Adicionar UserControl
- Nova Pasta
- Duplicar Form
- Definir como Form inicial
- Excluir Form

A alteração foi aplicada às edições Studio e Education.
